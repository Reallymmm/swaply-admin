# Swaply Admin — визуальный прототип (HTML + CSS)

Запуск в WebStorm:
    открыть папку проекта -> правый клик на index.html -> Open in -> Browser
    (или нажать значок браузера в правом верхнем углу редактора)

Файлы:
    index.html — разметка всех экранов (Обзор, Объявления, Пользователи, Категории)
    style.css  — все стили

Переключение экранов работает без JS, через :target (ссылки #listings, #users и т.д.).
